# 永久归档说明

2026-11-13 决定：**v4.2.0 为 Codex Remote Bridge 的最终版本，发布后永久停止更新并归档 GitHub 仓库。**

## 停止维护后的状态

- 不再开发功能，不再提供兼容性适配、安全补丁或问题处理。
- GitHub 仓库转为只读，已有源码、提交历史、标签及 Release 安装包保留。
- Star 图表的每日定时任务已取消；工作流源码保留供查阅和自行构建。
- 历史方案、路线图与审计报告移入或保留在 [archive](archive/README.md)，不再作为后续工作承诺。

## 继续使用与自行维护

现有本地安装不会因仓库归档被远程停用。运行仍取决于本机 Codex Desktop、系统及网络环境；未来兼容性和安全问题由使用者自行评估与维护。

最终版本及哈希文件见 [v4.2.0 Release](https://github.com/yuchen0x1/Codex-Remote-Bridge/releases/tag/v4.2.0)。升级前阅读 [签名限制及旧令牌处理](releases/v4.2.0.md)。可以按照 MIT 许可证分叉源码，参考 [构建说明](BUILDING.md) 自行构建。

## 保留与清理原则

保留源码、许可、历史文档、最终安装包及校验记录；保留本地 Android Release 私钥和签名配置，二者不提交 Git、不上传 Release。清理限定于当前项目内可重新生成的构建产物、临时测试文件和下载缓存；不清理用户会话、真实运行数据或系统全局缓存。
