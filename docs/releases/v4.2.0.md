# Codex Remote Bridge v4.2.0

发布日期：2026-11-13

> **最终版本 · 永久停止维护。** v4.2.0 发布后仓库转为只读归档，不再提供功能更新、兼容性适配、安全修复或问题处理。源码、历史文档及安装包保留供查阅与自行维护。

- **设备管理**：在「设置 → 配置 → 已连接设备」查看权限、最近访问和到期时间，撤销不再使用的设备会话。
- **安全配对**：新设备默认只读，需要遥控电脑时明确选择读写。修复只读凭据泄露主令牌的问题；轮换主令牌会同时撤销旧会话、待用配对码和实时连接。
- **稳定连接**：修复正常浏览器轮询被误限流、配对二维码生成失败和电脑快捷控制请求失败的问题。
- **可靠调度**：失败重试遵守次数上限；重新启用 cron 计划按其时区计算时间；删除或停用计划后不再安排失败重试。
- **更新支持**：Windows 可检查新版本并校验安装包大小与 SHA-256 后启动安装；Android/macOS 提供新版本下载入口。
- **数据隔离**：指定数据目录时，队列、日志和证书跟随保存；HTTP 测试启动命令可在 Windows 使用。
- **阅读与归档**：完善设置页栏宽、主题对比度、长文本换行和手机间距；增加本地更新日志与「版本与归档」入口，整理首页与历史文档，关闭定时更新任务。

## 升级注意

- 若曾分享旧格式 `主令牌:ro` 链接，请升级后**轮换主令牌并重新配对**。旧格式已暴露主令牌，更新代码本身不能收回它。
- 切换自定义数据目录不会自动搬移旧文件；生成新证书后，固定过旧指纹的客户端需核对后重新配对。
- Android APK 使用本次发布专用的本地 Release 密钥签名。若旧安装使用不同签名，系统不会允许直接覆盖；请先保留连接配置，再由用户决定是否卸载重装。
- Windows 安装包没有 Authenticode 签名；macOS 安装包没有 Developer ID 签名/公证。更新清单本身未签名，SHA-256 不能替代发行者认证。
- macOS 附件包含 Apple Silicon / arm64 Node 运行时，面向 Apple Silicon Mac；Intel Mac 需自行按源码构建。
- 验证覆盖服务回归、网页交互及平台构建；未验证真实跨版本安装、手机后台通知和长期运行，归档后不再安排补充验收。

安装文件与 `SHA256SUMS.txt`、`update-manifest.json` 位于本 Release 附件。Windows 请下载 Setup.exe，Android 请下载 APK，macOS 请下载 Installer.pkg。
