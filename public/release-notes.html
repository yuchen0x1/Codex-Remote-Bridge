v4.2.0 · 2026.11.13 · FINAL RELEASE

最终版本与更新日志

让手机连接电脑上的 Codex。这个版本完成设备权限、连接稳定性和阅读体验的最后整理。

本项目永久停止维护。

v4.2.0 为最终版本，发布后仓库转为只读归档。后续不再提供功能更新、兼容性适配或安全修复；源码、历史文档和已发布安装包保留供查阅与自行维护。

本次更新

  • 设备与权限：新设备配对默认只读；在「设置 → 配置」查看并撤销会话。主令牌轮换同时让旧会话、未用配对码和实时连接失效。
  • 连接与调度：修复正常轮询误限流、配对二维码与电脑快捷控制请求失败；失败重试遵守上限，停用或删除计划后不再重试。
  • 阅读与布局：设置页调整导航栏宽、主题对比度、说明文字换行和手机触控间距，新增版本与归档入口。
  • 更新与数据：Windows 校验安装包大小和 SHA-256 后启动安装；Android/macOS 提供下载入口。自定义数据目录同时管理队列、日志和证书。

升级前请阅读

  • 曾分享旧格式 主令牌:ro 链接的用户，需要轮换主令牌并重新配对。
  • Android 使用本次发布的本地 Release 密钥。旧安装签名不同时无法覆盖安装，请先保留连接配置。
  • Windows 没有 Authenticode 签名；macOS 没有 Developer ID 签名与公证。更新清单未签名，SHA-256 仅用于核验文件完整性。
  • 切换数据目录不会自动迁移旧数据。最终版本发布后不再跟进 Codex 或系统升级产生的兼容性变化。
